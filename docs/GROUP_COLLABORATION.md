# 部门群聊的决策、行动项与恢复

主持协作会在文本汇总之外保存结构化决策、行动项和未决事项。每条结构化事项必须引用本轮实际存在且没有报错的发言编号；行动项负责人必须是群内成员。未确定负责人或日期时保留 `null`，不会推测。模型返回旧版 Markdown 时仍保存正文，但标记 `structured: false`，不从正文猜造行动项。

行动项支持 `pending`（待处理）、`in_progress`（进行中）、`done`（已完成）、`cancelled`（已取消）。状态更新后，后续同一群内对话会收到有长度预算的结构化事项参考，包括最新状态与来源。其他群、同群的新独立对话不会继承这些事项。

## 中断后继续

只有当前对话最新的失败或停止轮次、有持久化检查点且仍有调用与耗时预算时，才可以恢复。恢复保留原轮次、已有发言、调用次数和耗时，只继续未提交的步骤；如果只是最终汇总失败，只重新汇总。服务重启会保守计入中断时正在进行的调用耗时，避免重启清空预算。

所有恢复会话均临时创建并强制只读，不复用可能带有待执行动作的部门运行实例。中高风险业务工具及流程委托会被权限钩子拒绝。恢复结束后清理临时运行实例；可见发言与结果继续保留。已经完成的轮次不能恢复；需要新增或修改业务操作时应明确发送新事项。

目前恢复针对**主持协作**。顺序协作的旧轮次仍保留中断标记，通过新事项继续，不会自动重放业务动作。

## 预算

主持协作保留原有讨论轮数和调用次数限制，并增加 `maxDurationMs`，默认 10 分钟，可配置 1 秒至 1 小时。到时会中止当前 Pi 运行，并停止后续调度。恢复沿用已消耗的调用次数与耗时；调整预算也必须满足既有配置边界。

可选 `maxTokens` 控制后续对话模型请求，范围 1–100000000。消耗只取 Pi 主会话真实 usage 差额，包含其工具往返和压缩用量；不使用字符估算。单次在途请求可能超出余额，完成后阻止下一次模型请求，因此这不是供应商端严格硬限额。供应商不报告 usage 时显示未知；若设置了 token 预算，则不再继续请求，不能把未知当作零。

启用 token 预算时会明确拒绝 `flow_*` 委托，因为现有委托子会话 usage 尚未回传主会话，不能让子运行绕过预算。不设置 token 预算时保留委托原行为，但展示的 Pi 主会话用量可能不包含这些子运行；外部 MCP 或业务系统内部产生的模型费用也不属于这项统计。

Pi 原生压缩使用独立模型运行时，其内部请求不受对话模型的逐请求前置拦截；压缩完成后累计其 usage，并在预算耗尽或用量未知时阻止后续对话请求。压缩和独立 usage 记录缺失用量时同样视为未知，即使更早的回复已报告有效用量。

`discussion.usage.costUsd` 当前为 `null`，表示没有可确认的供应商账单定价。`piReportedCostUsd` 是 Pi 目录模板给出的估值，也可能为 `null`，不能当作实际账单。由于自定义模型会沿用模板定价，当前明确拒绝 `maxCostUsd` 配置，不提供可能误导的金额硬预算。

## 接口

- `GET /api/agent-groups/:id`：`turns[].discussion.result` 为结构化结果；`turns[].discussion.usage` 返回 Pi 主会话报告用量；`turns[].budget` 返回调用/耗时/token 余量（未知为 `null`）；`turns[].canResume` 表示是否可恢复。
- `POST /api/agent-groups/:id/resume`，`{ "turnId": "..." }`：恢复指定轮次，要求 `session.run`。
- `PATCH /api/agent-groups/:id/actions`，`{ "turnId": "...", "actionId": "action-1", "status": "done" }`：更新行动项状态，要求 `session.write`。

结果中的 `decisions`、`unresolved` 使用 `{ id, content, sourceMessageIds }`；`actionItems` 使用 `{ id, title, ownerAgentId, deadline, status, sourceMessageIds }`。

## 验证

- `npm run agent-groups:moderation:selftest`：校验来源、负责人、日期、状态变更、检查点恢复、时限、上下文隔离和路由边界。
- `node scripts/agent-group-recovery-e2e.mjs`：临时 SQLite、本机假模型、真实 Pi、强制鉴权，实际验证重启、恢复、权限拒绝、流程委托阻断和行动项状态持久化；不调用真实外部模型。
